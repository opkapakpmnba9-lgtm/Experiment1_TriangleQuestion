# 实验一 类与对象

本工程依据实验指导书中的“题目1：三角形题目类（简单几何图形题库系统）”完成。

## 文件分工

- `TriangleQuestion.h`：类的声明。
- `TriangleQuestion.cpp`：成员函数的定义。
- `main.cpp`：生成对象并调用成员函数。
- `Experiment1_TriangleQuestion.sln`：Visual Studio 解决方案。

## 本实验使用的知识

- 类与对象
- `private` 和 `public` 访问控制
- 数据成员和成员函数
- 默认构造函数、重载构造函数、析构函数
- 对象调用成员函数
- 三角形三边合法性验证

本工程未使用继承、多态、虚函数、运算符重载、模板、`vector`、文件输入输出和动态内存。

## 与指导书步骤的对应关系

1. 设计三个私有数据成员 `sideA`、`sideB`、`sideC`。
2. 使用公有成员函数完成修改、获取、输出和合法性验证。
3. 默认构造函数生成三边为 3、4、5 的对象。
4. 重载构造函数按传入的三条边生成对象。
5. 在 `main.cpp` 中分别生成对象并调用周长、面积和类型判断功能。

## 打开方法

使用 Visual Studio 打开 `Experiment1_TriangleQuestion.sln`，选择 `Debug | x64` 后运行。

## 实验思考

### 1 访问控制和封装有什么作用

把三条边声明为 `private`，可以防止类外代码随意写入不合法的数据。类外只能通过公有成员函数修改数据，成员函数会先检查三条边是否都大于零以及是否满足两边之和大于第三边。把数据和操作数据的方法放在同一个类中，并隐藏不应由外部直接修改的实现细节，就是封装。

### 2 对象在什么时候产生和消亡

程序执行到对象定义的位置时，对象产生并自动调用构造函数。对象离开自己的作用域时，对象消亡并自动调用析构函数。本实验中的两个对象都定义在 `main` 函数内，因此它们在执行到各自定义语句时产生，在 `main` 函数结束时消亡。
